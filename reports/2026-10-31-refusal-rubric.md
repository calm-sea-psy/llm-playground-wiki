# 줄글 '답하지 않음' 판정 지시문 v1

F4 줄글 리포트의 '답하지 않음 (판정)' 칸을 채울 때 판정자(Claude 하위 에이전트)에게 준 지시문 그대로다. 2026-10-31, 답을 보기 전에 고정했다.
기준은 partial 판정기(`evaluation/partial_judge.py` `ITEM_GUIDE` 의 refused)와 같다. 판정 입력은 가린 번호 · 질문 · 답뿐이다 — 문항 종류 · 정답 · 문서는 싣지 않았다.

---

너는 위키백과 질문 응답 서비스의 답이 **질문에 실제로 답했는지**만 판정한다. 답이 맞는지, 문서에 근거했는지는 보지 않는다.

## 기준

- `refused: true` (답하지 않음): 질문이 실제로 묻는 것에 대한 답이 답에 없다. 다음이 모두 여기에 든다.
  - 답할 수 없다 · 알 수 없다 · 정보가 없다 · 알려 줄 수 없다고만 한 것
  - 묻지 않은 다른 해 · 다른 대상 · 다른 범위의 값을 대신 준 것 (예: 2027년을 물었는데 2026년 값만 줌, 태어난 곳을 물었는데 국적만 줌)
  - 질문 주제의 일반적인 설명만 하고 묻는 값은 주지 않은 것 — 글이 길어도 true
- `refused: false` (답함): 질문이 묻는 값이나 내용을 (일부라도) 실제로 준 것. 그 값이 맞는지 틀렸는지는 상관없다.
- 답이 "### 위키백과 문서에서" · "### 문서 밖 일반 지식" 두 칸으로 나뉘어 있으면 두 칸을 합쳐 본다 — 어느 한 칸이라도 묻는 값을 주면 false.
- "~는 알 수 없으나 문서 기준으로는 X 다" 처럼 단서를 달고 값을 준 것은 false.

## 예

- 질문 "2027년 대회 우승팀은?" · 답이 2026년 우승팀만 알려 준다 → true (묻지 않은 해의 값)
- 질문 "A 는 어디에서 태어났나?" · 답 "A 는 브라질의 축구 선수다" → true (태어난 곳이 없다)
- 질문 "A 는 어디에서 태어났나?" · 답 "A 는 부에노스아이레스 주에서 태어났다" → false
- 질문 "우리 회사 연차 규정은?" · 문서 칸 "직접적인 내용은 없습니다." · 일반 지식 칸 "알 수 없습니다." → true
- 질문 "B 의 인구는?" · 답 "최근 값은 알 수 없으나 2020년 기준 12만 명이다" → false

## 출력

문항마다 JSON 한 줄 (JSONL, UTF-8): `{"judge_id": "R001", "refused": true, "reason": "한 문장"}`
