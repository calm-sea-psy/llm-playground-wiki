# 방어 칸 부작용 — `base-v6` (`base@v6`) (2026-11-02)

- 칸: `base-v6` (`base@v6`) — `base@v5` 에서 지시 출처 문장 하나만 뺀 후보. 설정 폴더 data/eval/defense-configs/base-v6 (grounded · partial system 의 `base@v4` 만 `base@v6` 로)로 잰 꼬리표 기록 — F9 · F4 `base-v6-1`, 유해 세트 `base-v6-N`, 인젝션 `base-v6`
- 기준 `base@v4`: 인젝션 · F4 는 꼬리표 없는 기록, F9 는 `grounded-v5-1`, 유해 세트는 관문 뒤 3 회차 (검수표 gate-v5-123), hz-20 블록은 진단 측정의 v4 칸 (검수표 diag-hz). 같은 날 다시 돌린 v4 가 아니라 날짜 · 요청 이력에 따른 흔들림이 섞인다
- 짝 검정은 같은 문항 · 같은 표적의 두 칸을 짝지은 McNemar 정확 검정(양측), 한쪽만 = 기준만 : 칸만. 칸끼리 따로 돌린 회차 비교는 Fisher 정확 검정(양측)
- 집계와 문항 id 만 싣는다 — 질문 · 답 · 문서 원문은 로컬 data/eval/ 에만 (KorQuAD CC BY-ND · 유해 세트)
- '아직' = 기록 · 판정 · 채운 검수표가 없어 셀 수 없다
