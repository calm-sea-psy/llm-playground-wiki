## 결론

- **`high` 0.824914 유지 — 임시값을 확정값으로** (2026-10-29 사용자 결정, ADR-024)
- 근거: 답을 보기 전에 정한 규칙(지어냄 차이의 Newcombe 95% 구간이 0 을 포함하면 유지)대로. 차이 +4.1%p, 구간 −0.3 ~ +9.6 으로 0 을 겨우 포함하는 경계 결과다 — '차이 없음'이 아니라, 차이가 9.6%p 를 넘지는 않지만 4%p 안팎의 차이가 있는지는 이 표본으로 가르지 못한다는 뜻이다
- 문단 묶음 bootstrap 95% 는 +0.2 ~ +8.6 으로 0 을 뺐다 (2026-10-31 외부 리뷰 · 메인 확인으로 더함) — 같은 문단의 질문을 묶어 다시 뽑으면 차이가 0 위다. '유지'는 이 값이 아니라 답을 보기 전에 정한 Newcombe 규칙(−0.3 ~ +9.6, 0 포함) 때문이다 — 결과를 본 뒤 규칙을 바꾸지 않았다
- 지어냄은 두 구간 모두 잘못 읽음뿐이다 (다른 대상 · 수치 · 시점으로 옮김) — 문서에 없는 일반 지식을 끌어온 답은 없었다. 중간 구간에서는 첫 줄 표지 '못 찾음'이 이미 더 자주 partial 로 넘긴다 (20/150, ≥ 0.94 는 1/150)
- 올렸을 때의 비용: 0.83~0.94 질문이 grounded 를 건너뛰고 partial 로 가, 근거 있는 답(119/128)도 일반 지식이 섞인 칸으로 나간다. 세부 구간에서 지어냄이 한쪽 끝에 몰리지 않아 0.94 말고 다른 경계 후보도 없었다
- 다시 잴 때: grounded 프롬프트 · 답변 모델 · 리랭커가 바뀌거나, 운영 로그의 1위 점수 분포가 KorQuAD 와 크게 다르면 같은 단계(pool · strata · run --strata · judge-input · strata-report)로 다시 잰다
